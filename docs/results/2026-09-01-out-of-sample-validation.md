# KoreanStarterStrategy 독립 구간 검증

## 검증 설계

- 학습 구간: 2024-09-01 ~ 2025-09-01
- 독립 검증 구간: 2025-09-01 ~ 2026-09-01
- 학습 선택값: `buy_adx=19`, `buy_rsi=47`, `sell_rsi=77`, EMA 청산 미사용
- 비교 기준: 현재 기본값 `buy_adx=20`, `buy_rsi=45`, `sell_rsi=70`, EMA 청산 사용
- 페어, 타임프레임, 수수료, 주문 금액은 학습과 동일
